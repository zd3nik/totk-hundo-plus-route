TOTK Glitchless No AMIIBO HUNDO+
================================

Standard hundo speedrun (glitchless, no amiibo) plus:
* Clear all ??? from all device dispensers
* All chests within shrines (chest icon must appear next to shrine on map)
* All GSI chests & constructs
* All old maps
* All locked chests
* All mini-games
* All boss bokos
* All lynels
* All armor
* All armor set abilities unlocked
* All static spawn Phantom Ganons (the 2 in castle town, the 1 on Mekar island, and the 1 near Susuyai shrine are not static)
* Buy from all Beedles
* Read all Zora stone monuments
* Capture All compendium pics yourself (no pic purchases)
* Get a diamond from Hino (by rescuing him from all locations)
* Attend both Ashai classes in Gerudo town (get a smiling face in the adult class)

NOTES:
* Dog treasures are intentionally excluded
* Micro-management of weapons, health, armor, how to defeat enemies, etc is not detailed in this route doc. Dragon farming is highly time sensitive.  There are lynel and rocket shield farming segments, some of which can be skipped or done out of order to help ensure you arrive at dragons at the correct time.
